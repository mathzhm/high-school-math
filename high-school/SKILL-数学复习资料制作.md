# 高中数学复习资料制作 Skill（v4.0 · 数据驱动版）

## 一、总览

本套资料采用「单一数据源 + 四个自动生成页面」的数据驱动架构。
所有章节内容只写在一个文件 `chapters.js` 里，其余四个 HTML 页面全部
自动读取它来生成内容。**新增章节时只改 `chapters.js`，四个页面无需改动。**

### 文件清单（全部放同一层目录）

| 文件 | 作用 | 是否需手动改 |
|------|------|------------|
| `chapters.js` | 全站唯一数据源，存所有章节/知识点/题目 | ✅ 每加章节改这里 |
| `目录总页.html` | 首页，卡片式导航到各章节 | ❌ 自动生成 |
| `视频页.html` | 看视频 + 自测题（点击看答案） | ❌ 自动生成 |
| `做题本.html` | 做练习题，判分，答错自动进错题本 | ❌ 自动生成 |
| `错题本.html` | 读取错题，分组/排序/打印/导出 | ❌ 自动生成 |
| `videos/` | 所有视频文件（.mp4）统一放此文件夹 | ✅ 放视频 |
| `兔子.png` | 吉祥物图片，与 HTML 同层 | ✅ 放图片 |
| `脚本/` | 视频口播脚本源文件（.txt），不上线，仅供录制参考 | ✅ 每集写一个 |

## 二、数据结构（chapters.js）

```js
const CHAPTERS = [
  {
    name: "章节名（唯一，用于Tab/卡片/错题分组/网址参数，各文件必须一致）",
    desc: "一句话简介",
    topics: [
      {
        name:  "知识点名",
        video: "videos/文件名.mp4",   // 视频统一放 videos/，文件名要唯一
        quiz: {                        // ① 自测题：给"视频页"用，只看答案
          easy: [ {stem, options:[4项], answer:正确项索引0~3, note:"可选解析"} ],
          mid:  [ ... ],
          hard: [ ... ]
        },
        practice: {                    // ② 练习题：给"做题本"用，判分、答错入错题本
          easy: [ {stem, options, answer, note} ],
          mid:  [ ... ],
          hard: [ ... ]
        }
      }
    ]
  }
];
```

- `quiz` 与 `practice` 是两批**独立**题目，可完全不同。
- 章节数、知识点数、每档题数均**不限**，灵活配置。
- 未来可接入大模型 API 自动生成 `practice` 数据。

## 三、数据流（做题本 ↔ 错题本）

两者通过 `localStorage` 共享，**键名统一为 `math_wrong_book`**。

做题本答错时写入一条记录，字段**必须**如下（错题本按这套字段读取）：

```js
{
  id:      "w_时间戳_随机串",   // 唯一，用于单条删除
  chapter: "章节名",
  topic:   "知识点名",
  level:   "easy" | "mid" | "hard",
  stem:    "题目文字",
  correct: "A. 正确选项文字",
  chosen:  "B. 学生选的文字",
  time:    "2026/7/18 15:30:00"  // toLocaleString("zh-CN")
}
```

> ⚠️ **字段名必须两边完全一致**。历史上出过 bug：做题本存 `stem/correct/chosen`，
> 错题本却读 `question/answer/yourAnswer`，导致"数据存进去了但显示不出来"。

## 四、页面跳转规范（统一用 ?ch= 参数）

| 从 | 到 | 写法 |
|----|----|------|
| 目录页 | 某章节视频 | `视频页.html?ch=章节名` |
| 目录页 | 某章节做题 | `做题本.html?ch=章节名` |
| 目录页 | 某章节错题 | `错题本.html?ch=章节名` |

- 三个页面统一用 URL query 参数 `?ch=章节名`，不用 `#hash`，保持一致。
- 章节名含中文，链接里需 `encodeURIComponent()` 编码。
- 各页面用 `new URLSearchParams(location.search).get("ch")` 读取。
- 目录页顶部「全部错题」入口不带参数（`错题本.html`），错题本无参数时显示全部。

## 五、新增章节操作清单（4 步）

1. **写脚本**：为每个知识点写一集口播脚本（详见第六节），存进 `脚本/知识点名.txt`。
2. **录制视频**：按脚本录成竖屏 `.mp4`，放进 `videos/`，文件名与 `chapters.js` 里
   `video` 字段一字不差（如 `videos/均值不等式及其应用.mp4`）。
3. **编辑 chapters.js**：在 `CHAPTERS` 数组末尾（注意加逗号）粘一个新章节对象，
   填好 `name / desc / topics`，每个知识点填 `video / quiz / practice`。
4. **完成**。刷新页面，目录页、视频页、做题本、错题本全部自动更新，不改任何 HTML。

## 六、视频脚本与制作规范

每个知识点对应一集短视频。**先写脚本，再录制**，脚本与 `chapters.js` 里的
知识点一一对应（一个 `topics[]` 对象 = 一集视频 = 一个脚本）。

### 基本参数

- **画幅**：竖屏 9:16（与视频页左栏 `aspect-ratio:9/16` 匹配）。
- **时长**：每集约 3 分钟；口播文案约 600~660 字（正常语速 ≈ 3 分钟）。
- **风格**：口语化、有记忆口诀、用生活化类比，酷酷兔第一人称讲解。

### 单集结构（固定四段）

| 段落 | 时长占比 | 内容 |
|------|---------|------|
| ① 开场 | 约 10 秒 | "同学们好！" + 报本集知识点名（须与 `topics[].name` 完全一致） |
| ② 讲解 | 约 60% | 核心概念 + 记忆口诀 + 1 道现场演算的例题 |
| ③ 易错点 | 约 20% | 点明本知识点最常见的坑（对应 `practice` 里 hard 档的干扰项） |
| ④ 收尾 | 约 10 秒 | 一句话总结口诀 + "去做题本练一练 / 下一集见" |

### 脚本文案要点

- **例题复用题库**：例题优先从该知识点的 `quiz` / `practice` 里挑，保证
  "视频讲的"和"题目考的"一致，避免脱节。
- **给记忆口诀**：每集提炼一句好记的口诀，如"加减放心，乘除看正负，负数要调头"
  "大于取两边，小于取中间""一正、二定、三相等"。
- **知识点名一字不差**：脚本里说的、`chapters.js` 里写的、视频文件名，三者必须一致。

### 脚本文件规范

- 每个知识点一个脚本文件，命名与知识点同名：`脚本/不等式及其性质.txt`。
- `脚本/` 文件夹仅供录制参考，**不需要上线**，页面不读取它。

### 制作流程（3 步）

1. 按四段结构写脚本 → 存进 `脚本/知识点名.txt`。
2. 录制 → 导出竖屏 `.mp4` → 文件名与 `chapters.js` 里 `video` 字段一字不差。
3. 视频放进 `videos/`，刷新视频页即自动生效。

> ⚠️ 视频不显示 / 黑框：99% 是文件名对不上。检查 `videos/` 里的实际文件名
> 与 `chapters.js` 里 `video` 字段是否完全相同（含中文、标点、大小写、扩展名）。

## 七、样式规范（沿用「集合」专题基准）

- **视频页**：左右分栏——左栏竖屏视频（`flex:0 0 320px` + `aspect-ratio:9/16`，
  滚动吸顶 `position:sticky`），右栏知识点 Tab + 三档自测题；≤820px 自动堆叠为上下。
- **难度切换**：圆角胶囊标签，简单绿 / 中等橙 / 困难红，默认选"简单"。
- **题目卡片**：灰底圆角，视频页含"显示答案"折叠按钮，做题本点选项即时判分。
- **错题本**：默认"按知识点分类"分组（知识点标题带"X 题"计数），可切"按时间"倒序平铺。
- **吉祥物**：右下角 `position:fixed`，`兔子.png` 与 HTML 同层。

## 八、常见坑排查（重要！每条都踩过）

### 1. innerHTML 必须转义 —— 题目里的 `<` `>` `&` 会破坏页面
题目常含数学符号（如 `{x|1<x<5}`）。用 innerHTML 拼接时，`<` 会被当成 HTML
标签起始，把后面多个卡片"吞"进同一个块里，表现为**几道题挤在一个 block、边框套边框**。
**解决**：凡是插入 HTML 的用户文本，一律先过转义函数：

```js
function esc(s){
  return String(s ?? "")
    .replace(/&/g,"&amp;").replace(/</g,"&lt;").replace(/>/g,"&gt;");
}
```
四个页面渲染 `stem / options / chapter / topic / name` 等文本时都要包 `esc(...)`。

### 2. 反引号残留 —— 复制代码块后文件首尾多出多余标记
保存 HTML 时必须从 `<!DOCTYPE html>` 开始、到 `</html>` 结束，
删掉 Markdown 代码块的三反引号标记，否则页面顶部会出现多余文字。

### 3. 粘贴新函数忘删旧代码 —— 整个脚本崩溃
替换某个函数时若旧代码没删干净，残留片段引用了不存在的变量会报错，
导致**整个 `<script>` 停止运行、页面全空白**。替换函数务必删净旧的那一份。

### 4. 字段名不一致 —— 详见第三节，做题本存的和错题本读的必须同名。

### 5. localStorage 不互通 —— 同源问题
- 用本地服务器时，`localhost:5500` 与 `127.0.0.1:5500` 算两个源，数据不共享。
  打开做题本和错题本时地址栏前缀必须完全一样。
- 直接双击 `file://` 打开可能读不到 `chapters.js`（CORS），建议用本地服务器
  （VS Code Live Server 或 `python -m http.server`）。

### 6. 图片/视频不显示 —— 路径或文件名错
- 右下角出现"🖼️ 酷酷兔"替代文字 = `兔子.png` 没找到。
- 检查：文件名一字不差（含大小写，服务器/GitHub 区分大小写）、扩展名正确、
  与 HTML 同层（或路径写对，如 `images/兔子.png`）。
- 排查：F12 → Network 看是否有 `404 (Not Found)`，能看到浏览器实际找的路径。

### 7. ID / 章节名一致性
`chapters.js` 里的 `name` 是各页面 Tab、卡片、错题分组、跳转参数的**唯一钥匙**，
同一章节在各处引用必须完全一致（含标点、空格）。
