# 高中数学复习资料制作 Skill（v3.0）

> 一套用于快速生成高中数学各章节复习资料的标准化流程。
> 产出物为可离线运行的网页，配套视频脚本与分难度题库。
> 适用于集合、常用逻辑用语、函数、数列等任意章节，复用同一套结构。

---

## 一、整体架构（v3.0 标准）

本套复习资料由「四类文件」组成，各司其职，通过链接和浏览器本地存储协作。
所有章节都复用这一套结构，不再每章一套系统。

### 四类文件职责

| 文件 | 数量 | 职责 | 是否跨章节 |
|------|------|------|-----------|
| 目录总页.html | 全局 1 个 | 总入口。列出所有专题，每卡片三按钮：视频 / 做题 / 错题本 | 是 |
| 视频页（XX复习-视频版.html） | 每章 1 个 | 看三集视频讲解 + 分难度自测题（点击显示答案） | 否，每章独立 |
| 做题本.html | 全局 1 个 | 各章节选择题，Tab 切章节，自动判分，答错自动写入错题本 | 是 |
| 错题本.html | 全局 1 个 | 只读。展示/筛选/预览打印/CSV 下载做错的题 | 是 |

### 数据流

做题本.html（答错）──写入──▶ localStorage["math_wrong_book"] ──读取──▶ 错题本.html（展示）

- 做题本与错题本是「分家」的两个独立文件，不互相包含。
- 二者靠同一个 localStorage 键 "math_wrong_book" 传递错题数据。
- 前提：两文件在同一浏览器打开（localStorage 按浏览器隔离，不跨设备/浏览器）。
- 视频页完全独立，不参与错题数据流，只负责讲解 + 自测。

### 目录结构（推荐）

数学复习/
├── 目录总页.html            全局入口
├── 做题本.html              全局做题系统（多章节 Tab）
├── 错题本.html              全局错题本（只读展示）
├── 兔子.png                 吉祥物（各页右下角）
├── 集合复习/
│   └── 集合复习-视频版.html
└── 逻辑用语复习/
    └── 逻辑用语复习-视频版.html

> 关键：做题本.html、错题本.html、目录总页.html、兔子.png 放在同一层；
> 视频页放各自子文件夹。这样目录总页的相对路径链接才成立。

## 二、使用须知（两阶段协作）

本 Skill 含人工环节，采用「两段式协作」，中间由用户线下录制视频。

- 阶段一：生成三集视频脚本 + 分难度题库（AI 完成）。
- 人工环节：用户按脚本录制三集视频，命名为约定文件名。
- 阶段二：生成四类网页文件（AI 完成）。
- 变通方案：阶段二可先用占位文件名生成网页框架，视频录好后直接替换同名文件，实现解耦。

## 三、内容设计规范

### 视频脚本
- 每章拆 3 集，每集约 3 分钟 / 550–650 字。
- 语言口语化、亲切，开头结尾用吉祥物「活力酷酷兔」串场。
- 重点符号需口头强调，配合韦恩图/示意图讲解。

### 题库
- 每章 3 个知识点，每个知识点对应视频一集。
- 视频页自测题：每集三档（简单/中等/困难），每档 3 题，点击显示答案。
- 做题本：每章三档选择题，每档 3 题，四选项，自动判分。
- 每道题须标注 topic（知识点名），作为错题本分组依据。
- 出题后必须自查：集合类题目注意「互异性」，避免出现无解或多解争议题。

## 四、页面间跳转规范（锚点约定）

各页通过 URL 锚点（#）实现"打开即定位"，目录总页的按钮据此编写。

| 目标 | 链接写法 | 效果 |
|------|----------|------|
| 看某章视频 | `子文件夹/XX复习-视频版.html` | 打开该章视频页 |
| 做某章的题 | `做题本.html#do=章节名` | 打开做题本并自动切到该章节 Tab |
| 看某章错题 | `错题本.html#章节名` | 打开错题本并自动筛选该章节 |
| 看全部错题 | `错题本.html` | 打开错题本，显示全部章节 |

> 章节名必须与做题本 QUESTIONS 里的键、错题记录的 chapter 字段完全一致
> （如"集合""常用逻辑用语"）。

## 五、视频页样式规范（模板A · 固定标准）

所有章节视频页的「课后练习」区块必须统一采用以下样式：

1. 版块标题：「📝 课后练习」，左侧橙色竖线。
2. 难度切换：三个胶囊标签（简单/中等/困难），等宽圆角，选中态绿色。默认选中简单。
3. 题目呈现：灰底圆角卡片，题号加粗，选项写在括号内。
4. 每题配蓝色「显示答案」按钮，点击展开、变「收起答案」；答案区白底橙色左竖线。
5. 每档固定 3 题，选择题为主。
6. 吉祥物：position:fixed 固定在页面右下角，手机端自动缩小。

> 完整实现见基准模板 模板A-视频网页.html。新章节复制该模板、替换内容即可，样式勿改。

## 六、新增一个章节的标准操作清单

以后新增章节（如"函数"），按以下步骤，只改不重写：

### 步骤 1 · 做视频页

复制「模板A-视频网页.html」基准版 → 存为「XX复习/XX复习-视频版.html」
→ 按下表四个修改点替换内容，样式与逻辑无需改动。

#### 模板A-视频网页.html · 修改点

| 编号 | 位置 | 修改内容 |
|------|------|----------|
| 1 | `<title>` 与 `<h1>` | 改成本章专题名（两处需一致） |
| 2 | 三个 `.card` 的 `<h2>` | 改成三集知识点名称 |
| 3 | JS 的 `DATA` 对象 | 填入题目，格式 `["题干（选项在括号内）","答案"]`，每集三档、每档 3 题 |
| 4 | 三个 `<video src>` | 改成三集视频文件名（.mp4） |

样式规范（固定，勿改）：📝课后练习标题 + 绿色胶囊难度标签 +
灰底题卡 + 蓝色「显示答案」按钮（点击展开、变「收起答案」）+
橙线高亮答案 + 右下角固定吉祥物。详见第五节「视频页样式规范」。


### 步骤 2 · 把题目加进做题本.html
在 QUESTIONS 对象里新增一个章节键，格式：
    "函数": {
      easy:[ {stem,options,answer,topic}, ×3 ],
      mid:[ …×3 ], hard:[ …×3 ]
    }
- topic 字段是知识点名，会成为错题本的分组依据，务必填准。
- answer 是正确项索引（0~3）。

### 步骤 3 · 做题本.html 加面板与 Tab
① 顶部 main-tabs 加一个按钮：onclick="showPanel('p-hanshu',this)"
② 加对应 <div class="panel" id="p-hanshu"> …（含三档 diff-content，
   id 用 h-easy/h-mid/h-hard 前缀避免冲突）
③ applyHash() 里的 map 补一行： "函数":"p-hanshu"
④ 底部初始化补三行 renderQuestions("函数","easy"/"mid"/"hard", …)

> ★ 三处 id（Tab 的 showPanel 参数、<div id>、初始化容器 id）必须对应，否则空白。

### 步骤 4 · 目录总页.html 加卡片
把占位的 soon 卡片启用，或新增一张卡片，填三个按钮链接：
    <a class="btn-video" href="函数复习/函数复习-视频版.html">🎬 视频</a>
    <a class="btn-do"    href="做题本.html#do=函数">✏️ 做题</a>
    <a class="btn-quiz"  href="错题本.html#函数">📒 错题本</a>

### 步骤 5 · 错题本.html
无需改动。它自动读取 localStorage，按 chapter/topic 动态分组，
新章节的错题会自动出现、自动生成筛选按钮。

## 九、常见坑提醒

1. 保存 HTML 时误把聊天代码块外层的三个反引号复制进去，导致页面左上角出现
   「```html」字样——正确文件应以 <!DOCTYPE html> 开头、</html> 结尾。
2. 视频文件名与代码 <video src> 引用不一致，导致视频无法加载。
3. 做题本新增章节时三处 id 未对应，导致面板空白。
4. 做题本与错题本不在同一浏览器打开，错题数据看不到（localStorage 隔离）。
5. 章节名在 QUESTIONS 键、锚点、目录链接三处必须完全一致（含标点）。
