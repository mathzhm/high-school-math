# 📚 高中数学复习资料制作 Skill（v4.0 · 数据驱动版）

> 一套"视频讲解 + 分难度刷题 + 错题归集"的高中数学复习资料生成方案。
> 只维护一个数据文件，四个网页自动生成内容。
> 适用对象：为高中生制作课后复习 / 考前巩固材料的家长与老师。

---

## 🎯 这个 Skill 是做什么的

你只要提供一个知识点主题，它就能帮你产出一整套配套自学材料：**视频讲解脚本**、**分难度练习题**，以及一套**可直接在浏览器打开、带互动功能的复习网站**（视频页 + 做题本 + 错题本 + 目录总页）。

v4.0 的核心是**数据驱动**：所有章节内容只写在一个 `chapters.js` 文件里，四个网页全部自动读取它来生成。**新增章节时只改 `chapters.js`，四个网页一行都不用动。**

## 🗂️ 文件架构（全部放同一层目录）

| 文件 | 作用 | 是否需手动改 |
|------|------|------------|
| `chapters.js` | 全站唯一数据源，存所有章节/知识点/题目 | ✅ 每加章节改这里 |
| `目录总页.html` | 首页，卡片式导航到各章节的视频/做题/错题 | ❌ 自动生成 |
| `视频页.html` | 看视频 + 自测题（左右分栏，点击看答案） | ❌ 自动生成 |
| `做题本.html` | 做练习题，自动判分，答错自动进错题本 | ❌ 自动生成 |
| `错题本.html` | 汇总错题，按知识点/时间排序，打印、导出 CSV | ❌ 自动生成 |
| `videos/` | 所有视频（.mp4）统一放此文件夹 | ✅ 放视频 |
| `兔子.png` | 吉祥物图片，与 HTML 同层 | ✅ 放图片 |

## ✨ 核心功能

### 一、自动规划课程结构
把一个大知识点（如"集合"）按子知识点拆成若干短集，每集控制在指定时长内（如 3 分钟），并自动加上集间衔接过渡。

### 二、生成视频讲解脚本
为每一集撰写完整口播文案，含开场、概念讲解、例子、小结、下集预告。数学符号标注读法，重点结论加粗。

### 三、出分难度练习题
每个知识点自动配套简单/中等/困难三档题目（每档 3 题），附经过验算的标准答案。含参数的题目逐个候选解代回验证，避免出错。区分两批题：
- **自测题（quiz）**：给视频页用，只点击看答案；
- **练习题（practice）**：给做题本用，自动判分、答错入错题本。

### 四、生成互动复习网站（四页面联动）
- 📺 **视频页**：左右分栏——左侧竖屏视频（9:16 自适应、滚动吸顶），右侧知识点 Tab + 三档自测题，手机端自动堆叠。
- ✏️ **做题本**：章节 Tab + 难度切换，点选项即时判分，答错自动写入错题本。
- 📕 **错题本**：跨章节汇总错题，默认按知识点分类（带"X 题"计数），可切按时间排序，支持打印和导出 CSV。
- 🧭 **目录总页**：卡片式首页，每章一张卡，含"视频 / 做题 / 错题"三个入口。
- 🐰 右下角吉祥物陪学形象。

## 🔗 页面如何联动

做题本和错题本通过浏览器 `localStorage`（键名 `math_wrong_book`）共享错题数据：做题本答错 → 自动写入 → 错题本读取展示。跳转靠网址参数：

| 从 | 到 | 写法 |
|----|----|------|
| 目录页 → 某章视频 | `视频页.html?ch=章节名` |
| 目录页 → 某章做题 | `做题本.html#do=章节名` |
| 目录页 → 某章错题 | `错题本.html#章节名` |

## 🚀 怎么用（新增一个章节只需 3 步）

把 skill 文件内容（或 GitHub 链接）发给 AI，告诉它新主题信息，AI 会生成可粘进 `chapters.js` 的章节数据。你需要提供：

| 输入项 | 说明 | 示例 |
|--------|------|------|
| 知识点主题 | 要复习的章节 | 函数 / 数列 / 三角函数 |
| 子知识点 | 需覆盖的要点 | 单调性 / 奇偶性 / 周期性 |
| 单集时长 | 每集目标长度 | 每集 3 分钟 |
| 学生水平 | 目标难度 | 入门 / 复习 / 冲刺 |
| 素材（可选） | 视频、吉祥物图片 | xxx.mp4 / 兔子.png |

**操作三步：**
1. 把录好的视频放进 `videos/`，文件名唯一（建议含知识点特征）。
2. 在 `chapters.js` 的 `CHAPTERS` 数组末尾（记得加逗号）粘一个新章节对象，填好 `name / desc / topics`，每个知识点填 `video / quiz / practice`。
3. 刷新页面。目录页、视频页、做题本、错题本全部自动更新。

## 💡 实战经验（都是踩过的坑）

1. **插入网页的文本必须转义** —— 题目常含 `<` `>`（如 `{x|1<x<5}`），直接拼进 innerHTML 会被当成 HTML 标签，导致题目残缺、多题挤成一块。四个页面渲染文本前都要过 `esc()` 转义。
2. **做题本存的字段和错题本读的字段必须同名** —— 统一为 `id / chapter / topic / level / stem / correct / chosen / time`，否则"存进去了但显示不出来"。
3. **保存 HTML 要从 `<!DOCTYPE html>` 到 `</html>`** —— 删掉复制代码块残留的反引号，否则页面顶部会冒出多余文字。
4. **替换函数时旧代码要删干净** —— 残留片段会让整个脚本报错、页面全空白。
5. **用本地服务器打开** —— 直接双击可能因浏览器安全策略读不到 `chapters.js`；且 `localhost` 与 `127.0.0.1` 算两个源，错题数据不互通。推荐 VS Code Live Server 或 `python -m http.server`。
6. **图片/视频不显示先查路径** —— 文件名要一字不差（含大小写、扩展名），与 HTML 同层或路径写对；F12 → Network 看有没有 404。
7. **口播时长先按语速估算字数**，避免超时；**含参数的数学题逐一代回验算**，避免答案出错。
