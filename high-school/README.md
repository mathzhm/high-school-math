# 📚 高中数学复习资料制作 Skill

> 一键生成"视频讲解 + 分难度练习 + 互动网页"的高中数学复习资料
> 适用对象：为高中生制作课后复习/考前巩固材料的家长与老师

---

## 🎯 这个 Skill 是做什么的

这是一个"一键生成高中数学复习资料"的技能。你只要提供一个知识点主题，它就能帮你产出一整套配套的自学材料：包含**视频讲解脚本**、**分难度练习题**，以及一个**可以直接在浏览器打开、带互动功能的复习网页**。适合家长和老师为高中生制作课后复习、考前巩固的学习材料。

---

## ✨ 核心功能

### 一、自动规划课程结构
把一个大知识点（比如"集合"）按子知识点拆分成若干个短集，每集控制在指定时长内（例如 3 分钟），并自动加上集与集之间的衔接过渡。

### 二、生成视频串词脚本
为每一集撰写完整的口播文案，包含开场、概念讲解、例子、小结和下集预告。数学符号会标注读法，重点结论会加粗提醒，可直接用于录制视频。

### 三、出分难度练习题
每个知识点自动配套简单、中等、困难三个难度的题目（各 3 题），并附带经过验算的标准答案。含参数的题目会逐个候选解代回验证，避免出错。

### 四、生成互动复习网页
输出一个单文件 HTML 网页，功能包括：
- 📺 嵌入播放教学视频
- 🎚️ 按难度 Tab 切换练习题
- 👁️ 点击按钮显示 / 隐藏答案
- 🐰 可爱吉祥物陪学形象
- 🚀 进阶拓展知识卡片
- 📱 多集横向分列，手机端自动适配竖排

---

## 🧩 适用场景

- 家长想给孩子做**趣味化的课后自学材料**
- 老师想快速制作**可分发的复习网页**
- 需要把一个章节整理成**视频 + 练习 + 互动**三位一体的完整复习包

生成的网页可离线在浏览器打开，也可进一步导出成 PDF 用于打印刷题。

---

## 🚀 怎么调用

把这个 skill 文件的内容（或它的 GitHub 链接）发给 AI，并告诉它新的主题信息即可。需要提供：

| 输入项 | 说明 | 示例 |
|--------|------|------|
| 知识点主题 | 要复习的章节 | 函数 / 数列 / 三角函数 |
| 子知识点 | 需覆盖的要点 | 单调性 / 奇偶性 / 周期性 |
| 单集时长 | 每集目标长度 | 每集 3 分钟 |
| 学生水平 | 目标难度 | 入门 / 复习 / 冲刺 |
| 素材（可选） | 视频、吉祥物图片 | xxx.mp4 / 兔子.png |

AI 会按 skill 内置的流程和代码模板，帮你快速生成新章节的整套复习资料。

---

## 💡 特色亮点

这个 skill 沉淀了实际制作中踩过的坑，内置了几条重要经验：

1. **口播时长先估算**，按语速换算字数，避免内容超时。
2. **网页视频优先引用本地文件**，避免临时外链失效导致打不开。
3. **数学题必须逐一验算**，尤其含参数、涉及互异
